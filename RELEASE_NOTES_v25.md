# FiberLyse V25

V25 is a visual and usability-focused release of FiberLyse.

## Highlights

- modernized light and night-mode visual design;
- clearer visual hierarchy for primary, secondary, utility, and destructive actions;
- improved spacing and grouping of main analysis controls;
- cleaner file-queue/sidebar presentation;
- updated tab, input, button, and plot-tool styling;
- more integrated Matplotlib toolbar appearance;
- refreshed plot backgrounds, grid presentation, legends, and axis styling;
- responsive styling designed to persist across window resizing and theme switching.

## Scientific pipeline

V25 is intentionally cosmetic. The scientific analysis behavior is inherited from the preceding FiberLyse release and was not intentionally changed as part of the V25 visual redesign.

## Main analysis capabilities retained

- Neurophotometrics/Bonsai and custom CSV import profiles;
- separate-column and interleaved-row layouts;
- robust artifact handling;
- reference alignment and linear fitting;
- ΔF/F and zF normalization;
- smoothing;
- timestamp-derived sampling rate;
- adaptive/Nyquist-aware frequency analysis and PSD;
- AUC;
- batch compare and group average;
- centralized graph/data export;
- graph annotations and customization.
